# Lumina AI: Learn Your Way

Crie uma plataforma web moderna de estudos com inteligência artificial chamada “Lumina AI”, inspirada no conceito “Learning Your Way”, focada em personalização do aprendizado para estudantes brasileiros.

A aplicação deve ter design moderno, minimalista, responsivo e profissional, semelhante a plataformas educacionais premium e produtos de IA atuais.

OBJETIVO DA PLATAFORMA:

A IA deve atuar como um tutor inteligente capaz de:

- explicar conteúdos;

- resumir materiais;

- gerar exercícios;

- criar planos de estudo;

- adaptar explicações conforme o nível do aluno;

- acompanhar evolução e dificuldades.

ESTILO VISUAL:

- Interface futurista e limpa;

- Tema claro com detalhes em azul e roxo;

- Componentes modernos;

- Animações suaves;

- Dashboard elegante;

- UX parecida com produtos da OpenAI, Notion, Duolingo e Google Learning.

TECNOLOGIAS:

- Front-end em React + Next.js;

- Tailwind CSS;

- Framer Motion;

- Backend mockado inicialmente;

- Estrutura preparada para integração futura com APIs de IA.

PÁGINAS NECESSÁRIAS:

1. LANDING PAGE

Criar uma landing page moderna contendo:

- Hero section impactante;

- Título:

  “Aprenda do seu jeito com IA”

- Subtítulo explicando personalização inteligente;

- Botões:

  “Começar Agora”

  “Ver Demonstração”

- Cards explicando funcionalidades;

- Sessão “Como funciona”;

- Sessão de benefícios;

- Depoimentos fictícios;

- Footer profissional.

2. LOGIN E CADASTRO

- Tela moderna de autenticação;

- Login social;

- Inputs elegantes;

- Opção “Entrar como estudante”.

3. DASHBOARD PRINCIPAL

Criar dashboard com:

- Saudação personalizada;

- Barra de progresso;

- Calendário de estudos;

- Metas diárias;

- Estatísticas;

- Tempo estudado;

- Matérias em andamento;

- Recomendações da IA.

4. CHAT IA

Criar um sistema de chat inteligente semelhante ao ChatGPT.

Funções:

- enviar perguntas;

- receber respostas formatadas;

- suporte markdown;

- geração de listas;

- explicações didáticas;

- botão “Explicar mais simples”;

- botão “Gerar exercícios”;

- botão “Resumir resposta”.

Adicionar:

- histórico lateral;

- animações suaves;

- mensagens modernas;

- loading elegante.

5. UPLOAD DE PDF

Área para:

- upload de PDF;

- upload de imagens;

- visualização do documento;

- resumo automático;

- extração de tópicos principais;

- geração de flashcards.

6. GERADOR DE EXERCÍCIOS

Sistema onde o aluno escolhe:

- matéria;

- dificuldade;

- quantidade de questões.

A IA gera:

- questões;

- alternativas;

- correção;

- explicações.

7. PLANO DE ESTUDOS

Criar tela onde o aluno informa:

- prova;

- data;

- matérias;

- horas disponíveis.

A IA gera automaticamente:

- cronograma semanal;

- revisões;

- metas diárias.

8. PERFIL DO USUÁRIO

Mostrar:

- desempenho;

- matérias fortes;

- dificuldades;

- evolução;

- sequência de estudos;

- badges/conquistas.

FUNCIONALIDADES IMPORTANTES:

- Dark mode;

- Responsividade completa;

- Sidebar moderna;

- Componentização limpa;

- Código organizado;

- Estrutura escalável;

- Simulação de respostas IA;

- Estados de loading;

- Toast notifications;

- Empty states elegantes.

EXPERIÊNCIA:

A aplicação deve parecer um produto real de startup de IA educacional.

Adicionar:

- microinterações;

- hover effects;

- transições suaves;

- gráficos;

- barras de progresso;

- visual premium.

EXTRA:

Criar dados mockados realistas para:

- estudantes;

- progresso;

- exercícios;

- histórico;

- métricas.

IMPORTANTE:

- O projeto deve ser completo e navegável;

- Todas as páginas devem estar conectadas;

- Usar componentes reutilizáveis;

- Criar estrutura profissional de pastas;

- Gerar interface extremamente bonita e moderna.
